    Class BzTasks

    Beelzebub Task base class. User task classes should extend this and provide task methods. Methods that begin with _ or $ are excluded from the task registry (the $ prefix is reserved for framework-provided helpers).

    Example

    import bz, { BzTasks } from 'beelzebub';

    class MyTasks extends BzTasks {
      hello() { this.logger.log('hi'); }
    }
    bz().add(MyTasks);
